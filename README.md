# FightGame

这是一个使用 Python 和 Pygame 编写的简单 2D 格斗游戏示例，包含两名玩家、跳跃和攻击等基本功能。

## 运行方法

1. 安装依赖：`pip install -r requirements.txt`
2. 运行游戏：`python game.py`

## 操作说明

- **玩家 1**：A 向左，D 向右，W 跳跃，F 近战，G 远程
- **玩家 2**：← 向左，→ 向右，↑ 跳跃，L 近战，O 远程

攻击命中会减少对方生命值，生命值归零即宣告对手失败。

## 更新内容

最新版本加入了来自 OpenGameArt 的人物精灵，并添加远程攻击功能。玩家 2 的攻击键更改为 L，取消了数字键绑定。
